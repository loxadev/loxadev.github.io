Run private AI models

Loxa is a fast, simple local inference studio and CLI. An open alternative to Ollama and LM Studio — your models, your hardware, no cloud.

Star on GitHub Install 
$ loxa run llama3
→ pulling llama3 · loading · ready on :11434

$ loxa pull gemma
$ loxa serve
$ loxa studio   # open the desktop UI

⚠️ Work in progress — names reserved, building in the open.

Why Loxa

100% local

Models run on your machine. Nothing leaves your hardware — private by default.

One simple CLI

run, pull, serve, studio. Familiar if you've used Ollama.

Studio + CLI

A clean desktop app when you want it, a fast terminal when you don't.

Built in Rust

Native, lightweight, cross-platform. Powered by Rust + Tauri.

Install

npm
npm i -g @loxadev/cli
cargo
cargo install loxa
pip
pip install loxa
